# Registered confirmation of the CAPITALS cache intervention

The four-row donor transplant passed its development criterion. I reserved 32 new prompt IDs to assess whether the donor attention cache at the two changed country tokens and their following punctuation can recover the answers that the full updated document gives. All new documents have different content hashes from the earlier trials and their reserved cases. The comparison includes a donor-free query redirect, full and stale documents, a correction notice, recurrent-state transfer, local value transfer, and equally sparse selections by cache-change magnitude.
