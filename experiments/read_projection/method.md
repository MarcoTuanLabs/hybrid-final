# Sending the part of a recurrent update that a known suffix reads

A receiver already holds an old prefix cache. The sender has the updated cache and knows the four fixed chat-template tokens that follow the prefix. Both sides use the donor attention caches and convolution histories. The comparison measures how many additional bytes describe the change in the recurrent matrices, and how the reconstructed cache affects a freely generated answer.

SketchSSM derives the boundary-state effective query and reconstructs its read from a compact basis sketch. The following calculation specializes that identity to the actual four known suffix queries and transmits their span for one particular donor-minus-recipient update. Low-Bit Recurrent States also analyzes transport and radial suppression in the quantization setting. [SketchSSM, sections 3.2–3.3 and appendix C](https://arxiv.org/html/2609.33051v2) · [Low-Bit Recurrent States, section 2](https://arxiv.org/html/2609.30950v1)

For one head, let \(E_0\in\mathbb{R}^{d_v\times d_k}\) be the difference between the donor and recipient matrices at the boundary. The dimensions \(d_v\) and \(d_k\) count value and key coordinates. At token \(t\), let \(k_t\) and \(q_t\) be the key and read query, \(g_t\) the scalar retention gate, and \(\beta_t\) the update gate. Write \(I\) for the key-space identity and \(A_t=I-\beta_t k_t k_t^\top\), where the superscript denotes transpose. On a shared input trajectory, the homogeneous part of the recurrence carries the initial difference to \(E_t=g_tE_{t-1}A_t\). The new value is identical between these two trajectories and cancels in the difference.

Define the transported query \(w_t=A_1\cdots A_tq_t\) and the cumulative retention \(c_t=\prod_{i=1}^t g_i\). The read attributable to the initial difference is \(E_tq_t=c_tE_0w_t\). Build a matrix \(Q\) whose columns form an orthonormal basis for the span of the four vectors \(w_t\). The correction \(\widehat E_0=(E_0Q)Q^\top\) has the same action on every \(w_t\) because \(QQ^\top w_t=w_t\). For one edited layer, this preserves each read on that known suffix in exact arithmetic. For multiple layers the argument proceeds in causal order. Equal earlier reads imply equal incoming activations to the next layer on that trajectory. Free continuation after the four observed tokens lies outside the guarantee.

At each of 768 value heads in 9B, the sender encodes two 128-by-4 FP32 factors. This costs 4,096 bytes per head and 3 MiB in total. The dense FP32 update costs 48 MiB. The SVD and untransported-query controls carry the same number of values. The two-bit baseline packs four codes into a byte and sends FP16 minima and scales per value row. Its matrix payload is 3.375 MiB. The receiver reconstructs dense states for this experiment. Sender trace computation, the common donor attention and convolution, and dense resident storage remain relevant to any systems claim.

Finite-horizon observability is a classical result for time-varying systems. Recent hybrid-model work compresses recurrent states by adapting their SVD rank or quantizing them during inference. This experiment applies the read directions to synchronization of a specific paired cache over a known suffix.
