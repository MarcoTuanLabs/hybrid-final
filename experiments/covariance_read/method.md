# Which direction can a covariance contraction reach?

I adapted the curvature-conditioned query of Le et al. to a frozen four-bit Qwen3.5-9B checkpoint. The original models learn a query-dependent scalar gate during pretraining. Here I measured fixed gate values and let a write-informed variant select its gate before generation. These adaptations isolate the read geometry in the existing model. [Le et al.](https://arxiv.org/abs/2606.01294)

Let $k_j$ be the unit key at position $j$ in the shared query head, including all recipient prefix keys. At suffix slot $t$, let $m_t$ denote the total number of keys through that slot and let $\mu_t=m_t^{-1}\sum_{j=1}^{m_t}k_j$. I form the centered covariance $C_t=m_t^{-1}\sum_{j=1}^{m_t}(k_j-\mu_t)(k_j-\mu_t)^\top$, where the superscript $\top$ denotes transposition. The native query is $q_0$. The contraction subtracts $\lambda C_t q_0$ from $q_0$, where $\lambda$ controls its strength. I rescale the resulting vector to the Euclidean norm of $q_0$.

At each slot the write-informed version chooses among five equally spaced scalar values from zero to one by the same post-normalization objective used by the full reader. A further comparator uses the known source-key direction and applies an inverse regularized prefix-key covariance. This gives the comparator direct information about the write. The published whitened-key baseline instead inverts the unedited state Gram matrix. All interventions use the same 256-coordinate write and read the same four slots. Full-vocabulary top tokens determine behavioral success.

A scalar contraction also has a geometric restriction on a frozen backbone. Let $u=q_0/\lVert q_0\rVert_2$, $a=u^\top C_tu$ and $b=\lVert C_tu-au\rVert_2$. For $0\leq\lambda\leq1$ with $1-\lambda a>0$, the tangent of the angle from the native query is $\lambda b/(1-\lambda a)$. This ratio is nondecreasing in $\lambda$. Thus the observed angle at strength one bounds the rotation of every scalar gate on the same prefix and query. It does not bound the angles of a separately trained network with different keys and queries.
