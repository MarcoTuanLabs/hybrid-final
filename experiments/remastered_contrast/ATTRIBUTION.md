# Source and derived data

The questions, acceptable reference answers and source edits are from Shaochen Zhong and colleagues’ MQuAKE-Remastered CF3k split, revision b54712d4b464d7e2d4edccd4022f95ddbcb719e7. The authors release the dataset under CC BY 4.0. The original Princeton MQuAKE dataset supplied the single-relation question templates used by the conventional scope check. [MQuAKE-Remastered dataset](https://huggingface.co/datasets/henryzhongsc/MQuAKE-Remastered) · [ICLR paper](https://proceedings.iclr.cc/paper_files/paper/2025/hash/f782860c2a5d8f675b0066522b8c2cf2-Abstract-Conference.html) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) · [Original MQuAKE](https://github.com/princeton-nlp/MQuAKE)

The released inputs select 48 source cases and pool current updates from other cases as distractors. Each pool contains 512 unique updated subject–relation pairs. Each source case contributes one single-hop question and its first multi-hop paraphrase. Half of the source cases contribute actual edits to the pool. The other half retain their original answers. The pool construction protects the annotated original and updated paths. A consistency check excludes cases with disagreement between an edit and its annotated updated path. The archive includes the excluded source IDs, tested case IDs, original labels, document banks and exact input rankings.
