layer and position. Explicitly abbreviate S_{h,t} and Delta S_{h,t} as S_h and

d_v-dimensional read vector, N as headwise RMS normalization, epsilon as its

difference. Reuse the dimensions already defined for Equation 1.

Equation 5: define q_0 (native query), T (unit-length concatenated target), and
T_h (its d_v-dimensional headwise block). Define the Euclidean inner product
and cosine similarity. Sum over the same explicitly defined head set H.

Equation 6: define rho as the normalization denominator and J_N(x) as the
Jacobian of N at x. Reuse the identity definition with dimension d_v.

Whitening equations: define C as the state Gram matrix and lambda as the ridge
regularizer. Define matrix trace. Sum over the same head set H and use I_{d_k}
in the inverse. Replace the literal dimension 128 with d_k and state d_k=128
in both evaluated models. Display the definitions without splitting a formula
across pages.
